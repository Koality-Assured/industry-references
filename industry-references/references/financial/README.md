# Financial Compliance & Quantitative References

Canonical financial compliance, regulatory frameworks, and quantitative modeling references have been federated to the domain spoke repository:
👉 [`Koality-Assured/financial-advisement-router`](https://github.com/Koality-Assured/financial-advisement-router)

## Federated Scope

The following reference frameworks and tools now reside natively within [`financial-advisement-router`](https://github.com/Koality-Assured/financial-advisement-router):
- **Sarbanes-Oxley Act (SOX) ITGC**: Internal controls over financial reporting (ICFR).
- **Payment Card Industry Data Security Standard (PCI DSS v4.0.1)**: CDE scoping, 12 requirements.
- **GLBA Safeguards Rule (16 CFR Part 314)**: NPI protection, WISP, MFA, and incident reporting.
- **FFIEC Cybersecurity Assessment Tool (CAT)**: Banking cybersecurity maturity domains.
- **NYDFS 23 NYCRR 500**: Cybersecurity mandates for financial institutions.
- **SEC Regulation Best Interest (Reg BI)** & **FINRA Rule 2214**: Retail investment analysis tool disclosures.
- **IEEE 754 Decimal Arithmetic**: Pure Decimal money and ledger execution.

Agents and engineers requiring financial modeling, DCF valuation, portfolio optimization, or financial regulatory compliance should operate directly within the `financial-advisement-router` spoke.
