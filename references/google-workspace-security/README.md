# Google Workspace security best practices

External reference guides and machine-readable control catalogs for Google Workspace (formerly Google Suite) security, identity, data loss prevention, and service administration.

> [!NOTE]
> **Advisory Reference**: Content in this directory is advisory reference material derived from official Google Workspace documentation, CIS Google Workspace Benchmark v1.3.0, and NIST SP 800-63-4. It is not an agent instruction set.

## Reference topics

| Document | Focus area |
| --- | --- |
| [`workspace-admin-security.md`](./workspace-admin-security.md) | Domain tenant admin, SSO/SAML, 2FA enforcement, SCIM, context-aware access, DLP, ZDR |
| [`drive-docs-security.md`](./drive-docs-security.md) | Drive sharing perimeters, trust rules, external collaboration restrictions, link privacy |
| [`gmail-security.md`](./gmail-security.md) | Email security: SPF, DKIM, DMARC, MTA-STS, BIMI, approval gates, outbound DLP |
| [`calendar-meet-security.md`](./calendar-meet-security.md) | Calendar sharing boundaries, Google Meet encryption, access locks, attendance logging |
| [`catalogs/google-workspace-security-controls.json`](./catalogs/google-workspace-security-controls.json) | Compact machine-readable security controls and audit checks |
