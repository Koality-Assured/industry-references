# Matter classes

This page tells an operator which corpus to open. It does not state the elements of any offense or claim.

## Criminal, civil, administrative

| Class | Who decides | Typical federal corpus | Typical state corpus |
| --- | --- | --- | --- |
| Criminal | Court, on a charge brought by a public prosecutor | Title 18 USC; Federal Rules of Criminal Procedure; USSC Guidelines where a sentence is federal | The criminal or penal title on the state page; state criminal rules; a separate criminal court of last resort where the state page confirms one |
| Civil | Court, on a claim between parties (including many claims by or against the government) | Title 28 USC for jurisdiction and procedure; Federal Rules of Civil Procedure; Federal Rules of Evidence | Civil procedure title or code; evidence rules; trial and appellate rules on the state page |
| Administrative | An agency, under a statute, with judicial review afterward | Title 5 USC (administrative procedure); CFR title for that agency; Federal Register for the rulemaking | The administrative code and register on the state page; the organic statute that created the agency |

Name the class before opening a second corpus. A licensing dispute is usually administrative until someone files a case. A lawsuit about that license is civil. A prosecution is criminal.

## Classes operators skip

Open these only when the question is actually about them. Confirm the corpus on the federal or state page. Do not treat this list as a holding.

| Class | Where to start |
| --- | --- |
| Constitutional | Federal Constitution page, then that state's constitution section. A statute cannot answer a constitutional question by itself. |
| Bankruptcy | Federal. State collection and exemption law can still matter. Start with the inferior-courts page, not a state trial docket. |
| Immigration | Federal. State criminal pages do not supply the Immigration and Nationality Act. |
| Tax | Federal internal revenue code for federal tax. State revenue titles for state tax. They are different sovereigns. |
| Military justice | Federal uniform code, not a state penal code. |
| Family, probate, and guardianship | Almost always state civil or a dedicated state code. Confirm on the state page. |
| Workers' compensation and unemployment | Usually a state agency plus a state statute. Administrative first. |
| Professional licensure and attorney discipline | State supreme court or a state agency. Rules of professional conduct are not the ABA model rules unless the state page says the state adopted a text. Do not copy the ABA model rules. |
| Local government | City or county ordinance. See [`local-government.md`](./local-government.md). |
| Tribal | Separate sovereign. See [`tribal-law.md`](./tribal-law.md). |
| Territorial | Not a state page. See [`territories.md`](./territories.md). |

## Federal and state together

Identify both sovereigns when a fact pattern can trigger either. Preemption, removal, and habeas are legal conclusions. Record the official sections only after they are fetched. Do not announce preemption from this table.

## Currency

Codified pages lag session laws and slip opinions. If the matter date is recent, check session laws and the court of last resort's slip or order page, not only the code index.
